# SAI2 FX Studio（非官方插件）

为 [sai2工作台](https://github.com/isaysth/sai2-workbench) 增加**液化 / 模糊 / 滤镜 / 调整**的独立玻璃浮窗，直接对接 SAI2 当前图层。

> ⚠️ **非官方作品**：与上游 PainterAnkry、小红书分享者均无隶属或背书关系。
> 使用前请**备份画作**。注入类工具可能触发杀软告警。详见 `THIRD-PARTY-NOTICES.md`。

## 它做什么 / 不做什么

- ✅ 玻璃质感独立浮窗，与工作台主题统一
- ✅ 连接 SAI2 图层面板（读图层名、点选图层）
- ✅ 抓当前图层 → 液化/模糊/滤镜/调整 → 贴回 SAI2
- ✅ 参数实时预览、撤销、复位
- ❌ 不含、不分发任何注入二进制（`sai2_agent.dll` / `sai2_injector.exe`）
- ❌ 不修改 SAI2 本体，只通过公开命名管道 + 剪贴板交互

## 安装

### 第 1 步：安装上游注入套件（自行下载）

1. 从 <https://github.com/PainterAnkry/sai2-plugin-suite/releases> 下载最新的 `sai2-plugin-suite-x.xx.zip`
2. 解压到一个固定目录（例如 `D:\sai2-plugin-suite`）
3. **右键以管理员身份运行**解压目录里的 `添加白名单.bat`（否则杀软会拦截 `sai2_agent.dll`）
4. 记住这个目录，第 3 步要用

> 64 位 SAI2、Windows 10/11。本插件不提供也不修改这些二进制。

### 第 2 步：安装本插件

在工作台「插件」页点「安装」→ 选择 `sai2-fx-studio-0.1.0.zip`。
（或把本目录整个复制到工作台的 `plugins/` 目录后重启。）

### 第 3 步：配置

在插件中心打开 FX Studio 的配置：
- **SAI2 插件套件目录**：填第 1 步解压的目录（里面应有 `sai2_injector.exe`）
- 需要自动注入可勾选「打开浮窗时自动运行注入器」

## 使用

1. 在 SAI2 打开一幅画
2. 点工作台工具栏「FX Studio」（或右键 `.sai2` 文件 →「用 FX Studio 处理」）
3. 先确保已注入（未注入时点「刷新图层」会提示离线；可勾选自动注入或手动运行上游的 `启动插件面板.bat`/注入器）
4. 在图层列表点选目标层 → 点「抓取当前图层」
5. 选效果和参数 →「预览」→ 满意后「应用并贴回」

## 已知限制

- **画布补边**：当前按"抓到多大贴多大"回贴。上游通过读取 `.sai2` 文件头精确画布尺寸做补边；此功能列为本插件后续增强，复杂文档可能有 1~15px 落位偏差。
- **液化性能**：JS 位移场在大画布（如 5000×5000）上明显慢于上游 C++；用降采样预览缓解，提交时全分辨率计算。
- **合成键**：依赖 SAI2 响应 Ctrl+A/C/V（2023.04.05 版实测有效）；个别版本可能需要改走菜单自动化。
- 本机 SAI2 若为修改版，注入兼容性可能与上游测试环境不同。
