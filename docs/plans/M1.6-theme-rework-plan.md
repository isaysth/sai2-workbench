# M1.6 计划：外观体系重构（玻璃 / 简约 × 明暗 × 背景）

> 写于 2026-11-17 · 状态：已确认并交付（交付说明见 `M1.6-delivery.md`）
> 起因：用户指出当前 `acrylic / light / dark` 三个平级主题把「风格」和「配色」混在一起，需要拆成正交维度，并支持自定义背景图。

---

## 1. 目标（这个阶段结束时你能做什么）

1. 设置里选**风格**：玻璃 / 简约。
2. 选**明暗**：浅色 / 深色（两个风格各支持）。
3. 玻璃风格下可调**不透明度**与**模糊度**；简约风格下这两项不出现。
4. 选**背景**：纯色（跟随明暗，浅=近白 / 深=近黑）、自定义图片（导入本地图片）、桌面（窗口真透明，看穿到桌面）。
5. 导入的背景图在简约风格下铺在最底层，侧栏/标题栏/卡片仍是实色，图片从留白和间隙露出来。
6. 旧配置自动迁移，不会因为升级丢设置。

验收动作：四个组合（玻璃浅 / 玻璃深 / 简约浅 / 简约深）× 三种背景，共 12 张截图逐个看。

## 2. 数据模型

### 2.1 类型（`src/shared/types.ts`）

```ts
export type ThemeName = 'glass' | 'minimal'        // 外观风格
export type ColorScheme = 'light' | 'dark'         // 明暗
export type BackgroundMode = 'solid' | 'image' | 'desktop'

general: {
  theme: ThemeName
  scheme: ColorScheme
  background: BackgroundMode
  /** 相对 data/backgrounds/ 的文件名；空串表示没选图 */
  backgroundImage: string
  /** 玻璃面板白色（深色下是黑色）浓度，0~0.95，仅 glass 生效 */
  glassOpacity: number
  /** 玻璃模糊半径 px，0~40，仅 glass 生效 */
  glassBlur: number
  thumbnailSize: number
  cardSize: 'sm' | 'md' | 'lg'
}
```

`acrylicOpacity` 正式改名为 `glassOpacity`（它已经和亚克力材质无关了，现在纯 CSS）。

### 2.2 旧配置迁移（`src/main/config.ts`）

`version: 1 → 2`，在 `mergeDefaults` 之后、`sanitize` 之前跑一次：

| 旧值 | 新值 |
|---|---|
| `theme: 'acrylic'` | `theme: 'glass', scheme: 'light'` |
| `theme: 'light'` | `theme: 'minimal', scheme: 'light'` |
| `theme: 'dark'` | `theme: 'minimal', scheme: 'dark'` |
| `acrylicOpacity: x` | `glassOpacity: x`，删除旧键 |

迁移是幂等的（已经 `version >= 2` 就不跑），迁移完写回一次盘。

## 3. CSS 架构

### 3.1 三个 dataset 互相正交

`documentElement` 上挂三个属性，组合出 12 种状态：

```html
<html data-theme="glass|minimal" data-scheme="light|dark" data-bg="solid|image|desktop">
```

CSS 文件拆成三段，**只有「表面」变量被 4 套配色覆盖，文字/描边/阴影按明暗共享**，避免 4 份完全重复：

```
① 布局常量        :root { 字体、尺寸、圆角、动效 }
② 明暗调色板      [data-scheme='light'|'dark'] { --text-*, --accent, --border, --shadow-*, --log-* }
③ 风格表面        [data-theme='glass'|'minimal'][data-scheme='light'|'dark'] { --bg-chrome, --bg-content, --bg-card, --bg-elevated }
④ 背景层          [data-bg='solid'|'image'|'desktop'] { --bg-wall, --bg-wall-image }
```

### 3.2 表面变量对照

| 变量 | 玻璃·浅 | 玻璃·深 | 简约·浅 | 简约·深 |
|---|---|---|---|---|
| `--bg-chrome` | `rgba(255,255,255, α×0.95)` | `rgba(30,33,40, α×0.95)` | `#ffffff` | `#1b1f25` |
| `--bg-content` | `rgba(250,251,253, α×0.93)` | `rgba(22,25,30, α×0.93)` | `#f2f4f8` | `#14171c` |
| `--bg-card` | `rgba(255,255,255, min(1,α×1.95))` | `rgba(38,42,50, min(1,α×1.95))` | `#ffffff` | `#22262d` |

玻璃仍然是**纯乘法**（α=0 时彻底归零，这条之前的成果必须保住）。

深色玻璃额外约束：α < 0.15 时面板几乎不可见，靠 `--edge-line` 和 `--sheen` 撑出边界；文字用浅色 + **深色**光晕（浅色背景下是白晕，这里反过来）。

### 3.3 背景层怎么落地（不新增 DOM）

直接把背景画在 `body` 上，不改层级结构：

```css
body {
  background-color: var(--bg-wall);
  background-image: var(--bg-wall-image, none);
  background-size: cover;
  background-position: center;
}
```

- `solid`：`--bg-wall` 取明暗对应的近白/近黑
- `image`：`--bg-wall-image: url("sai2img://bg/<文件名>")`
- `desktop`：`--bg-wall: transparent`，窗口 `transparent: true` 直接看穿

简约风格 + `image`/`desktop` 时，额外把 `--bg-content` 设为 `transparent`，这样图片/桌面能从内容区露出来，而卡片和侧栏保持实色（保证看图不偏色）：

```css
[data-theme='minimal']:is([data-bg='image'], [data-bg='desktop']) { --bg-content: transparent }
```

## 4. 背景图存取

1. 新协议 `sai2img://`：`registerSchemesAsPrivileged` + `protocol.handle`，只映射 `data/backgrounds/` 目录，拒绝 `..` 越界。
   （顺带为 M2a 的缩略图协议打样，之后 `thumb://` 走同一套。）
2. 选图 IPC `app:pickBackground`：`dialog.showOpenDialog` 过滤 png/jpg/webp/bmp → 复制到 `data/backgrounds/bg-<时间戳>.<ext>` → 删除上一张 → 返回文件名。
3. 清图 IPC `app:clearBackground`：删文件、清配置。
4. 上限 8MB，超了直接拒绝并提示（避免用户拖一张 50MB 的 4K 原图进来）。

## 5. 设置页改造

「外观」拆成四块，从上到下：

```
主题风格   [玻璃]  [简约]            ← 两张预览卡，选中态描边
明暗       [浅色]  [深色]            ← 分段按钮
玻璃参数   不透明度 ▬▬▬●▬▬ 22%
           模糊度   ▬▬▬▬●▬ 24px     ← 仅玻璃风格出现，简约时整块隐藏
背景       [纯色] [图片] [桌面]
           ├ 图片：缩略预览 + 「选择图片」「清除」
           └ 桌面：提示「面板会看穿到桌面，建议搭配较高不透明度」
```

简约风格下不显示玻璃参数块（不是禁用，是整块不渲染），避免用户以为坏了。

## 7. 本阶段不做

- 背景图不提供「模糊 / 暗化 / 填充方式」选项（固定 `cover` + 一层很薄的纱，够用再说）
- 不做多背景图轮播、不支持视频/GIF 背景
- 玻璃风格的「真实桌面模糊」（PureRef 那种）仍需 FFI，继续留在 M3 备选
- 不做配色自定义（强调色主题色）

## 8. 风险

| 风险 | 应对 |
|---|---|
| 深色玻璃在深壁纸上看不清面板 | α 越高越实；再靠 1px 亮描边 + 深色文字光晕；实测对比度不达标就把深色玻璃的 α 下限抬到 0.18 |
| 12 种组合漏改某套变量 | 自测脚本按矩阵截图 + 采样像素，逐格核对理论值 |
| 老配置迁移出错导致设置丢失 | 迁移前先备份 `config.json` → `config.v1.bak`；迁移失败保留原文件并回退默认 |
| 自定义协议在打包后路径失效 | 协议 handler 用 `dataDir` 动态解析，不写死相对路径 |

## 9. 需要你确认的点

1. 上面 12 种组合的矩阵范围对不对（有没有多余的）？
2. 背景「纯色」是否需要让你**自己挑颜色**（不只是黑/白）？当前计划是只给跟随明暗的近白/近黑两种。
3. 简约风格下是否也允许 `桌面` 背景（内容区看穿桌面、卡片实色）？
