# M1 交付说明：骨架可跑

> 交付时间：2026-11-17
> 对应计划：`docs/plans/M1-plan.md`（状态：已交付）
> 对应需求：v1.10 · 交付计划 M1

## 一、能做什么

1. **三栏窗口**：左侧导航（启动 / 文件管理 / 运行日志 / 插件中心 / 设置）、中间内容区、右侧详情面板，两条竖线可以拖动改宽度，**重启后宽度保持**。
2. **三套主题**：亚克力（默认）/ 浅色 / 深色，点一下立刻变，**重启后保持**；亚克力有透明度滑块（30%~95%）。
3. **真毛玻璃**：本机 Win11 build 26200，系统级亚克力已生效 —— 侧栏、标题栏、详情面板能透出背后的窗口并模糊（见 `docs/shots/m1-acrylic-screen.png` 是系统级截屏，网页截图看不到这一层）。
4. **实时日志页**：程序每一步都显示，能按级别过滤、按关键字搜索、暂停/继续、清空、打开磁盘日志文件、全屏展开。
5. **设置页**：主题切换、亚克力透明度、缩略图大小（后两项的显示效果待 M2a），以及数据目录、插件目录、系统信息。
6. **自定义标题栏**：拖动、最小化、最大化/还原、关闭都正常，关闭时保存窗口位置与大小。
7. **配置自愈**：配置文件被写坏时自动备份并重建，不崩、不白屏。

## 二、怎么验证（3 分钟）

```bash
cd sai2-workbench
npm run dev          # 开发模式，改代码会自动刷新
# 或看构建产物：
npm run build && npx electron .
```

> 如果 `npx electron` 报 `requestSingleInstanceLock` 之类的错，是环境里带了 `ELECTRON_RUN_AS_NODE=1`，用
> `env -u ELECTRON_RUN_AS_NODE ./node_modules/electron/dist/electron.exe .` 启动。

按顺序试这几条，正好覆盖本阶段全部验收点：

| # | 操作 | 应该看到 |
|---|---|---|
| 1 | 打开程序 | 3 秒内出界面，默认亚克力主题，侧栏底部蓝色「启动 SAI2」 |
| 2 | 拖动左右两条竖线 | 宽度跟着变，松手后重启程序仍是这个宽度 |
| 3 | 设置 → 点「浅色」「深色」 | 立刻变色，无闪烁；重启还是上次那套 |
| 4 | 设置 → 亚克力 → 拖透明度 | 侧栏玻璃厚度实时变化（松手才保存） |
| 5 | 运行日志页 | 能看到启动过程的每条日志；切「只看错误」应显示为空 |
| 6 | 日志页点「暂停」→ 再点「继续」 | 暂停期间不追加新行，继续后补齐 |
| 7 | 双击标题栏 | 最大化/还原正常 |

## 五、与计划的偏差（4 处）

| 偏差 | 原因 |
|---|---|
| 日志弹窗 → 页面内全屏 | 独立窗口需要主进程 `setWindowOpenHandler` + 新 preload 注入，M1 内做会牵出 IPC 拷贝问题，改成全屏不损失功能，挪到 M3 |
| 亚克力默认透明度 **65% → 58%** | 65% 换算后实际不透明度 0.79，玻璃感太实；58% 换算 0.74，纯白壁纸下白字对比度仍 > 7:1，安全且更透 |
| 多 3 个调试环境变量（`SAIGUI_SHOT` / `SAIGUI_THEME` / `SAIGUI_PAGE`） | 我无法用眼睛看界面，靠它们自动截图核对观感；对正式使用无影响，生产不设就是普通启动 |
| 样式文件 4 个（themes / base / glass） | 计划写 3 个；组件样式并进 base 后仍显臃肿，按主题与玻璃分层更清楚，未新增概念 |
