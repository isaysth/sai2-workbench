# M1.6 交付说明：外观体系重构（风格 × 明暗 × 背景）

> 交付日期：2026-11-17 · 对应计划：`docs/plans/M1.6-theme-rework-plan.md`
> 需求文档 v1.15 / 开发文档 v1.2 已同步。

---

## 一、能做什么

1. **风格**：玻璃 / 简约，两张预览卡切换，点一下立刻生效。
2. **明暗**：浅色 / 深色，两种风格都支持 —— 所以是四套配色，不是两套。
3. **玻璃参数**：不透明度（0~95%）+ 模糊度（0~40px）两个独立滑块，**只在玻璃风格下出现**。
4. **背景**：纯色 / 自定义图片 / 桌面 三选一。
   - 纯色：浅色=近白的双光斑，深色=近黑的双光斑
   - 自定义图片：点「图片」直接弹选图框，拷进 `data/backgrounds/`，可换可清
   - 桌面：窗口真透明，直接看穿到壁纸
5. **旧配置自动迁移**：升级后不用重新设置，原文件备份为 `config.v1.bak`。

---

## 二、怎么验证（3 分钟）

启动后进设置页，按顺序点：

1. **风格**切到简约 → 不透明度和模糊度**整块消失**（不是灰掉）。
2. **明暗**切深色 → 面板、卡片、文字全部换色，状态栏右下角显示「简约 · 深色」。
3. 切回**玻璃**，把不透明度拖到 **0%** → 面板底色彻底消失，只剩文字和描边。
4. **背景**切到「桌面」→ 能看见你桌面壁纸。
5. 背景点「图片」→ 选一张图 → 图片铺在最底层；玻璃风格下它会被模糊（模糊度拖到 0 对比一下）。

## 四、已知问题（诚实列出）

1. **模糊滑块只在「图片背景」下看得见效果。** 纯色背景没有细节可糊；桌面模式读不到窗口外的画面（浏览器内核限制，Electron / WebView2 一致）。设置页的说明文字已按当前背景动态切换。
2. **玻璃 + 高饱和图片 + 低不透明度 = 文字可读性下降。** 这是物理必然：30% 白纱压不住高饱和色。已做三重缓解（默认 32%、面板系数提到 1.5、双层文字光晕），但如果你把浓度拖到 5% 又用一张极艳的图，文字还是会吃力。
3. **简约 + 图片时内容区不是全透明**，而是压了 55%~62% 的纱。原因是页面标题这类不被卡片包裹的元素会直接压在花图上，实测读不清。图片仍然看得出是什么，但比玻璃风格下淡。
4. **深色玻璃在深色壁纸上看不清面板边界。** 建议深色 + 桌面组合时把不透明度调到 25% 以上，设置页会给出黄色提示。
5. 自定义背景只支持静态图片（PNG/JPG/WebP/BMP），不支持 GIF / 视频；不提供"模糊背景图""暗化背景图"这类独立设置。

## 五、与计划的偏差（3 处）

| 计划 | 实际 | 原因 |
|---|---|---|
| 面板系数 0.95 / 内容 0.93 / 卡片 1.95 | **1.5 / 1.35 / 1.95** | 按 0.95 做出来面板只有 30% 白，压在高饱和图上时次级文字和面板边界一起被吃掉（截图对比过）。滑块语义是"浓度"，不是精确 alpha |
| 简约 + 图片时内容区全透明 | **压 62% / 60% 的纱** | 全透明时页面标题直接压在花图上，灰字配彩底等于看不见 |
| 文字光晕一层 | **两层（1px 硬边 + 5px 柔晕）** | 单层柔晕在高饱和背景下太淡，文字仍然糊 |

另外**多加了一个东西**：图片背景额外压一层纱（浅 0.2 / 深 0.3），同样是为了可读性，计划里没写。

## 六、下一个阶段（M2a，需你确认后开工）

范围不变：文件夹监听（chokidar）+ SAI2 缩略图 jssf 解码移植 + 瀑布流。

这次重构给 M2a 留了三个现成的地基：

- `sai2img://` 协议已跑通，缩略图可以换 host 直接复用（`thumb://`）。
- 整窗模糊层已经建好，缩略图铺上去之后模糊参数会真正有意义。
- 卡片表面变量已和明暗解耦，网格不需要为「深色主题」写第二套配色。

## 七、本轮先给你的一件事

**「模糊」这个参数以前是个摆设，现在不是了。** 图片背景是页面内的东西，`backdrop-filter` 能采到它 —— 所以玻璃风格 + 图片背景时，拖动模糊度能看到真实的磨砂前后对比。这是把背景做成"可导入图片"带来的意外收益。
