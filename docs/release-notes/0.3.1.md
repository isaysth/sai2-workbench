### 1. 关窗后托盘菜单点不动（已修）

以前把主窗口关掉、只留托盘时，右键菜单虽然弹得出来，但「显示主窗口」「切换为悬浮窗」点了都没反应，只剩「退出」有效。

原因：主窗口只在启动时创建一次，关掉之后没有任何重建路径，两个动作发现窗口已销毁就直接静默返回了。

现在：托盘菜单（含悬浮窗入口）发现窗口不在就**重新建一个**并接回原有状态，首项文案也改成了更准确的「重新打开主窗口」。

### 2. 插件自带的页面，按钮终于能点了

插件可以通过 `addPage` 往侧栏加自己的页面，但页面跑在沙箱 iframe 里，没有任何回调通道——**按钮画得出来，点了没反应**。

现在补了一条消息通道：插件页面里的按钮可以触发该插件注册的动作，结果（成功/失败原因）会回执到页面上。

> 直接受益的是 FX 插件（现名「SAI2 特效工坊」）的**管理面板**：一键开始、只启动 SAI2、只打开浮窗、连接注入器、打开插件目录、完整工具面板——六个按钮都能用了。

### 3. 插件中心新增「重启工作台」

装完插件、改完配置，有时要整个程序重开才干净。以前只能托盘退出再双击打开。

现在插件中心右上角有「重启工作台」：点一下、确认，程序自己关库 → 关监听 → 重启（不会留半截数据库文件）。安装成功的提示里也会提醒你「若界面没变化请点重启」。

### 4. 插件卡片上直接开关插件

插件列表每个卡片右侧多了一个开关，点一下就能启用/禁用，不用先点进详情。系统级插件（内核服务）的开关是灰的、点不动。

**顺带修掉一个让人困惑的 bug**：以前判断「这个插件是不是启用着」用的是「是否正在运行」，于是一个「等依赖」或「加载失败」的插件会被显示成「未启用」，你去点「启用」，状态其实没变——看起来就像按钮坏了。现在按「是否被禁用」判断，四处口径统一。

### 5. FX 插件改中文名：SAI2 特效工坊

插件列表、侧栏页面、浮窗标题、工具栏菜单统一叫「**SAI2 特效工坊**」（原 SAI2 FX Studio）。

插件 ID 与仓库名没变，**老用户升级不用重装**，配置也不会丢。

### 升级方式

- 老用户：解压**增量升级包**覆盖到原文件夹，数据与配置都保留
- 新用户：解压**整包**，双击 `sai2工作台.exe`
- 升级前建议先在设置页「数据备份」导一份，图个安心
