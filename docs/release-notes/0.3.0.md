### 1. 数据备份与恢复（F23）

设置页新增「数据备份」卡片：

- **一键导出**：把 `data\config.json`、`data\index.db`、`data\backgrounds\`、`plugins\`（自制插件）打成一个 zip，自己挑存放位置
- **一键恢复**：选回备份 zip，程序先校验条目（防路径穿越），确认后关闭数据库 → 把现有数据改名留底（`.bak-时间戳`）→ 覆盖 → 自动重启
- **打开数据目录**：一键跳到程序旁边那个 `data\` 文件夹

> 备份**不含** `cache\thumbs\`（缩略图缓存，能自动重建）和 `logs\`。

### 2. 打开器路径「自动查找」（N-008）

打开器详情页多了「自动查找」按钮：扫常见安装目录（深度 ≤4、跳过系统目录），

- 命中一个 → 直接填进路径框
- 命中多个 → 给下拉让你挑
- 一个都没命中 → 提示手动输入，不报错

以前「配置区在页面顶部、详情里空白」的误导也一并修掉了，配置就在 openers 插件详情里。
