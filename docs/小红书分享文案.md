⚡️ 一个按钮拉起画图软件

插件中心即装即用，内置 9 个（打开器、缩略图、主题演示…），配置表单自动生成。会写点 JS 就能自己扩，可玩性拉满。

双击 exe 就用，不写注册表、不联网。整个文件夹拷进 U 盘，换电脑数据跟着走；放 Program Files 会自动切到 AppData，完全不用操心。

## 五、发布前必看（避坑清单）

- **外链别直接放正文**：小红书对 GitHub 链接敏感，容易被限流。正文只写「GitHub 搜 sai2工作台」，把完整链接放**主页简介**或**评论区置顶**。
- **别写「点赞私信领取」**：这类话术会被判营销。用「链接在主页」「有需要的姐妹自取」这种自然表达。
- **图片比例**：小红书信息流偏爱 3:4 竖图，横截图务必拼版或加留白，别直接发 16:10。
- **发布时间**：晚上 20:00～23:00 画师群体在线高峰，首发病假日前一晚流量更好。
- **首图文字要少而大**：手机上只有指甲盖大小，一行主标题 + 一行小字足够。
- **评论区自己先占一楼**：发完立刻在评论区补一句「下载方式放这儿👇GitHub 搜 sai2工作台，或点我主页」，引导互动。
- **杀软误报提前说**：程序未做代码签名，部分杀软可能误报，评论区可补一句「杀软误报加信任即可，开源无广告」减少顾虑。
- **持续维护**：有人问下载就热情回，评论互动率直接影响后续推荐。
